How orders reach your print provider

    
GitHub Pages hosts static files only, so this page can't (and shouldn't) hold secret API keys. Pick one of three routes — you can start with A and graduate to C.


    
A · Fastest: product links checkout.mode = "links"

    
    
      
  1. Create your products in Printful, Printify, Gelato or Gooten and connect them to a store that can take payments (Shopify, Etsy, WooCommerce, Wix…).
    2. 
      
  2. Copy each product's public page URL (or a Shopify “Buy Button” / Stripe Payment Link).
    3. 
      
  3. Paste it as buyUrl on the product — or use variantBuyUrls if each colour/size has its own link.
    4. 
      
  4. Set CONFIG.checkout.mode to "links". Customers browse here and complete payment on that page; the provider fulfils automatically.
    5. 
    


    
B · Manual: email orders "email"

    
The bag opens an email to you with every line item. You place the order in your provider's dashboard yourself. Good for testing demand with zero setup.


    
C · Fully automatic: your own endpoint "endpoint"

    
    
      
  1. Deploy a tiny serverless function (Cloudflare Workers, Netlify, Vercel — all have free tiers).
    2. 
      
  2. Put its URL in CONFIG.checkout.endpoint. The shop POSTs the bag as JSON: { items:[{ productId, name, color, size, qty, unitPrice, providerVariantId }], subtotal, shipping, total, currency, successUrl, cancelUrl }.
    3. 
      
  3. Your function creates a Stripe Checkout session and returns { "url": "…" } — the shop redirects the customer there.
    4. 
      
  4. A Stripe webhook (checkout.session.completed) then creates the order with your provider's API, using the providerVariantId you stored in providerIds. Keep API keys in the function's secrets — never in this file.
    5. 
    

    
Starting point for the function (Cloudflare Worker) — always re-check prices on the server, never trust prices sent by a browser:


export default {
  async fetch(request, env) {
    const cors = {
      "Access-Control-Allow-Origin": "https://YOURNAME.github.io",
      "Access-Control-Allow-Headers": "Content-Type"
    };
    if (request.method === "OPTIONS") return new Response(null, { headers: cors });

    const { items, successUrl, cancelUrl } = await request.json();

    // SECURITY: replace it.unitPrice below with a price looked up
    // from your own server-side price list.
    const body = new URLSearchParams({
      mode: "payment",
      success_url: successUrl,
      cancel_url: cancelUrl,
      "shipping_address_collection[allowed_countries][0]": "US",
      "shipping_address_collection[allowed_countries][1]": "CA"
    });
    items.forEach((it, i) => {
      const p = `line_items[${i}]`;
      body.set(`${p}[quantity]`, it.qty);
      body.set(`${p}[price_data][currency]`, "usd");
      body.set(`${p}[price_data][unit_amount]`, Math.round(it.unitPrice * 100));
      body.set(`${p}[price_data][product_data][name]`, `${it.name} (${it.color} / ${it.size})`);
      body.set(`${p}[price_data][product_data][metadata][variant_id]`, it.providerVariantId || "");
    });

    const res = await fetch("https://api.stripe.com/v1/checkout/sessions", {
      method: "POST",
      headers: {
        Authorization: `Bearer ${env.STRIPE_SECRET_KEY}`,
        "Content-Type": "application/x-www-form-urlencoded"
      },
      body
    });
    const session = await res.json();
    return new Response(JSON.stringify({ url: session.url }), {
      headers: { ...cors, "Content-Type": "application/json" }
    });
  }
};


    
Adding your real artwork & mockups

    
    
      
  • Export your artwork as a transparent PNG/WebP, around 1000 px wide, and put it in an images/ folder next to index.html. Make a gold/light version for dark garments and a dark version for light garments.
    • 
      
  • Add it to DESIGNS (or use the builder's “New design” option).
    • 
      
  • For photo-real previews, download the mockups from your provider's mockup generator and paste each one into a colour's image field.
    • 
      
  • Upload your full-size print files (usually 4500×5400 px PNG) only inside your provider's dashboard — not here.
    • 
    

  


  
  

    
Publish with GitHub Pages (free)

    
    
      
  1. Create a new public repository on GitHub (e.g. my-store).
    2. 
      
  2. Click Add file → Upload files, drop in index.html and your images folder, then Commit.
    3. 
      
  3. Open Settings → Pages. Under “Build and deployment”, choose Deploy from a branch, select main and / (root), then Save.
    4. 
      
  4. After a minute your shop is live at https://YOURNAME.github.io/my-store/.
    5. 
      
  5. Optional: add your own domain under Settings → Pages → Custom domain.
    6. 
    

    
Updating the shop later

    
Open index.html on GitHub, press the pencil icon, edit CONFIG, DESIGNS or PRODUCTS, and commit. The live site refreshes within a minute or two.

    
Before you take real orders

    
    
      
  • Check shipping, returns and privacy wording is accurate for your region, and add any policy pages your jurisdiction requires.
    • 
      
  • Make a test purchase end to end.
